Introduction

This page is a complete reference of Java Flight Recorder (JFR) events for OpenJDK {{version}} ({{tag}}{{#permanentURL}}, permalink{{/permanentURL}}, {{date}}){{#graalVMInfo}}, and GraalVM {{version}} ({{tag}}){{/graalVMInfo}}. JFR events are the foundation of JVM profiling and observability — they capture runtime data such as garbage collection pauses, CPU load, thread activity, class loading, compilations, and more. The events listed here are collected from the JFR event configuration and the OpenJDK source code. Visit the jfreventcollector repository for more information. This is also where you can contribute additional event descriptions, if you don't want to contribute them directly to the OpenJDK. The site generator lives on GitHub, too.

For each JFR event you'll find its fields, default configuration profiles (continuous / profiling), real-world examples from the Renaissance benchmark, and — where available — source code context to help you understand what each event means during JVM performance analysis.

This page is maintained by Johannes Bechberger of the SapMachine team at SAP and contributors.

Some events have fake end times/durations; these are hidden in the event description here.
